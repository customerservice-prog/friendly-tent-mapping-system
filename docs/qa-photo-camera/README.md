# Photo workspace evidence

Actual Chromium/WebGL captures from an isolated test account, not a live customer session. The venue is a public-domain reference photograph by Yinan Chen: https://commons.wikimedia.org/wiki/File:Gfp-house-on-a-nice-lawn.jpg. The photograph is unchanged; RentSketch places its real renderer over it. Test reference dimensions are illustrative inputs, not measurements of this property. No accuracy or fit is certified by these images.

- `desktop-preview.png`: corrected photo-camera face winding, continuous white canopy, furniture, contact shadow and compact controls.
- `mobile-preview.png`: responsive view and corrected texture allocation after viewport resize.
- `tent-before-after.png`: original and rebuilt meshes under the same camera and lights.

The fixture access banner is test data. No live customer data, account password, payment or MFA enrollment was changed.
