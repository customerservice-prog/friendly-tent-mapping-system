Common questions

Built to make event layouts approachable.

What can I design with RentSketch?

RentSketch focuses on event layouts involving tents, tables, chairs, dance floors, lighting and other supported event-rental items.

Do I need design or CAD experience?

No. The guided workflow is intended to help regular customers start from event details and then move into a visual layout.

Can rental companies add RentSketch to their own website?

Yes. RentSketch is being built as an embeddable, tenant-based system so rental companies can connect their own branding, catalog and workflow.

Can I use both 2D and 3D?

Yes. The goal is one event scene viewed in both a practical overhead layout and a 3D visualization.
